# Coding Plan: Wasserstein Φ-SFS, Null Replicates, Z-scores, and P-values

## 1. Goal

Replace the current scalar Φ-SFS calculation with the first Wasserstein
distance between two normalized unfolded site-frequency spectra (SFS), then
calibrate the observed focal-to-control distance against repeated
control-to-control comparisons with the same site count and age-matching
design.

For one focal category, the production result will include:

- the raw observed Wasserstein distance;
- the complete finite-site neutral null distribution;
- a null-standardized Z-score;
- a one-sided add-one Monte Carlo P-value;
- SFS and CDF arrays needed to reproduce the result; and
- diagnostics for direction, matching quality, site count, control reuse, and
  sensitivity to the fixed neutral reference.

This is a breaking statistical change. The implementation must use a new output
schema and must not silently read or combine existing `phi-sfs-v1` results.

## 2. Statistical design

### 2.1 Dataset types, fixed focal set, and matched neutral sets

Expose the two roles explicitly in the CLI:

- `-A/--a-type {TE,SNP}` selects the focal dataset and defaults to `TE`;
- `-B/--b-type {SNP}` selects the control dataset and defaults to `SNP`.

The initial implementation therefore supports the primary `TE`-versus-`SNP`
analysis and a `SNP`-versus-`SNP` negative-control analysis. A TE control pool
(`-B TE`) is out of scope for this implementation. Record both types in the
output metadata and summary so the analyses cannot be confused.

Let $A$ be the observed focal set after the orientation, genotype,
callability, and ARG-quality rules appropriate to its declared type, with
exactly $M$ retained sites. If `-A TE`, use the TE rule below. If `-A SNP`, use
exactly the same SNP eligibility, posterior-orientation, and $p$ versus $1-p$
mixture used for the B SNP pool. Exclude every row selected for $A$ from the B
candidate pool before matching, including in `SNP`-versus-`SNP` analyses.

Generate:

- one neutral reference set $B_0$; and
- $R$ neutral comparison sets $B_1,\ldots,B_R$.

Generate all $R+1$ control sets with the existing age-matching procedure. For
each replicate $r=0,\ldots,R$:

1. multinomial-bootstrap the focal A sites;
2. construct that replicate's bootstrap focal-age CDF $G_r^*$; and
3. match a same-sized SNP set $B_r$ to $G_r^*$ with the existing optimizer.

Every $B_r$ must:

- contain exactly $M$ retained SNPs;
- match its independently bootstrapped focal-age target $G_r^*$;
- use the same individuals and the same non-polarity filtering, callability,
  and data-quality rules as $A$;
- be generated by the same SFS-blind algorithm; and
- be selected without using allele frequencies or Φ-SFS.

TEs and SNPs deliberately do **not** use the same polarity rule:

- **TEs:** retain an insertion only when it is inferred to be derived in at
  least 50% of the ARG draws. After that upstream retention decision, insertion
  presence is the derived allele in the TE SFS.
- **SNPs:** do not apply the TE at-least-half-derived filter. Use every ARG draw that
  can orient the two observed SNP alleles. If the observed ALT frequency is
  $p$, a draw in which ALT is derived contributes at frequency $p$, while a
  draw in which REF is derived contributes at frequency $1-p$.

Equivalently, if $q$ is the fraction of usable ARG draws in which ALT is
derived, the SNP contributes the posterior mixture

$$
q\,h(k,n)+(1-q)\,h(n-k,n).
$$

This remains valid for any $q\in[0,1]$; in particular, a SNP is not discarded
when $q\le0.5$. Draws that cannot orient either observed allele remain an ARG
quality/missing-orientation issue and must be counted separately rather than
treated as evidence for either direction.

Use $R=1000$ for the initial production default, fixed in every category so that all
categories are calibrated with equal precision. The matcher publishes $R+1+K$ sets,
with $K=200$ spares by default (1201 sets). $B_0$ must pass matching QC; the nulls
are the first $R$ QC-passing non-reference sets in replicate-ID order, and the run
fails if fewer than $R$ pass. QC is age-only, so this selection is SFS-blind. The
minimum add-one P-value is $1/1001$ in every category. (Decided 2026-09-25 in
response to CODE_REVIEW_ROUND10 Finding 2; the recent disjoint bundle passed QC in
95/100 sets, so publishing exactly $R+1$ sets would almost never complete.)

Designate one of these identically generated sets as $B_0$ before examining any
SFS. The remaining sets are $B_1,\ldots,B_R$. $B_0$ is special only because it
is held fixed in the distance calculations; it is not matched to a different
age target and does not use a different candidate pool or algorithm.

The observed focal SFS $A$ remains fixed. The existing focal-site age
bootstrap is used
only in constructing the age target for each matched SNP set. Consequently, the
neutral null incorporates finite SNP-set sampling, focal-age-target variation,
matching error, and control-set variation without a second or nested bootstrap.

### 2.2 Relationship to the current bootstrap matcher

`bootstrap_target_matcher.py` already implements the required matching design:
it independently bootstraps the focal sites, constructs a bootstrap focal-age CDF,
and matches one SNP set to that target for every replicate. Do not add an
observed-target matching mode and do not create a special matcher path for
$B_0$.

The only matcher-side configuration changes are to request $R+1$ published sets
instead of $R$ and to require `--disjoint-replicates` (below). The existing `bootstrap-target-matches-v1` bundle already
contains the required replicate IDs, bootstrap seeds and counts, bootstrap
target CDFs, matched rows, matching distances, QC results, and reuse summaries.

Retain the current matching-QC interpretation. For replicate $r$, let

$$
V_r=W_1(G_r^*,G_{mathrm{observed}})
$$

measure natural focal-age bootstrap variation and let

$$
E_r=W_1(G_{B_r},G_r^*)
$$

measure residual SNP-matching error. The existing
`matching_error_ratio = E_r / V_r`, together with its absolute error cap when
$V_r$ is small, determines whether the SNP set is close enough to its target.
Only QC-passing sets enter the Φ-SFS analysis.

Require the matcher's `--disjoint-replicates` mode, its production setting, so
that no control SNP appears in more than one of $B_0,B_1,\ldots,B_R$. Shared
controls make two sets resemble each other more than independent draws would,
which deflates the $B_i$-to-$B_0$ null distances and makes the test
anticonservative. With reuse allowed, the matcher reached a maximum reuse of 30
on the in-gene target (`BOOTSTRAP_HPC_VALIDATION.md`). The effect of that reuse
on $B_i$-to-$B_0$ distances has not been measured, so reuse cannot be treated as
harmless. Because $B_0$ is one of the disjoint replicates, it is automatically
disjoint from every $B_i$ and needs no special removal step.

Disjoint mode depletes the candidate pool sequentially, so later sets are drawn
from a slightly smaller pool than earlier ones. At 100 replicates of the in-gene
target this was not detectable: the sets consumed 1.77% of the 23,026,051-row
pool, and `E_r` showed no trend with replicate index. $R+1=1001$ sets is a
different regime. For the 4,067-site in-gene target they need 4,071,067
controls, 17.7% of the pool, and for the 35,512-site production category they
need 35,547,512, more than the whole pool. Before production:

- check that $(R+1)\,M$ fits within the eligible candidate pool for every
  category, and fail rather than silently falling back to reuse;
- re-measure the depletion check (matching error `E_r` and the null distance
  $D_i^0$ against replicate index) at the production replicate count; and
- for categories where 1001 disjoint sets do not fit, prespecify the fallback
  (a smaller $R$ with its higher minimum P-value, or another design) before
  any SFS is examined.

Record the maximum reuse of the bundle, which must be 1, and the overlap of each
$B_i$ with $B_0$, which must be 0.

### 2.3 Equal site count must be enforced upstream

The current `phi_sfs.py` drops sites with fewer than 20 callable individuals
after matching. That can leave $A$, $B_0$, and the $B_i$ with different numbers
of eligible sites, defeating the site-count calibration.

Move eligibility into target and candidate construction, using separate
orientation rules for the two variant classes:

1. build a reusable VCF eligibility mask using the shared `phi_sfs` genotype,
   callability, and data-quality rules;
2. apply the at-least-50%-derived ARG rule only to the TE target before
   fixing $M$;
3. for both a SNP A set and SNP B candidates, keep sites with any usable
   posterior orientation and store their full $q$ values rather than
   thresholding them at 0.5;
4. exclude SNPs that fail the shared non-polarity eligibility rules or have no
   usable ARG orientation; and
5. assert in `phi_sfs.py` that every final set has exactly $M$ eligible sites.

Do not silently downsample all sets to the smallest post hoc count. That would
change the focal set and its age target after matching. A mismatch should fail
with a message directing the user to rebuild the target and controls with the
eligibility mask.

## 3. Core numerical implementation

### 3.1 Preserve projection and normalization

Keep the existing:

- `hypergeometric_projection()`;
- SNP polarity-weighted site projection, including the $p$ versus $1-p$
  orientation mixture;
- `(k, n, polarity)` projection cache;
- set-level accumulation; and
- normalization after summing all retained polymorphic mass.

The new statistic operates on the resulting normalized SFS arrays and does not
change their construction.

### 3.2 Replace `PhiResult`

Replace the old residual-mass fields with a result that describes the
Wasserstein calculation and direction diagnostics. For example:

```python
class PhiResult(NamedTuple):
    value: float
    cdf_a: np.ndarray
    cdf_b: np.ndarray
    cdf_residual: np.ndarray
    bin_residual: np.ndarray
    mean_daf_difference: float
```

### 3.3 Implement the one-dimensional distance directly

Add a pure function with no file I/O:

```python
def phi_sfs(
    a: np.ndarray,
    b: np.ndarray,
    *,
    daf: np.ndarray | None = None,
) -> PhiResult:
    ...
```

Validation:

- both inputs are one-dimensional, finite, nonnegative, and have equal length;
- each sums to one within a declared tolerance;
- `daf` is finite and strictly increasing; and
- its length equals the number of SFS bins.

For the default projection, set `daf = RETAINED_BINS / PROJECTION_SIZE`.
Calculate:

```python
cdf_a = np.cumsum(a)
cdf_b = np.cumsum(b)
cdf_residual = cdf_a - cdf_b
value = np.sum(np.abs(cdf_residual[:-1]) * np.diff(daf))
```

The last CDF difference is zero because both spectra sum to one, so it has no
interval to its right. On the equally spaced projected grid, the expression is
equivalent to multiplying the sum of absolute CDF differences by `1 / m`;
including the final zero changes nothing.

Also calculate:

```python
bin_residual = a - b
mean_daf_difference = np.dot(a - b, daf)
```

The Wasserstein distance is unsigned. The mean-DAF difference and residual
arrays provide direction without changing the definition of Φ-SFS.

### 3.4 Implement null calibration as a second pure function

Use a separate result type:

```python
class PhiCalibration(NamedTuple):
    observed: float
    null: np.ndarray
    null_mean: float
    null_sd: float
    z_score: float
    p_value: float
    exceedances: int
```

and function:

```python
def calibrate_phi(observed: float, null: np.ndarray) -> PhiCalibration:
    ...
```

For null distances $D_1^0,\ldots,D_R^0$, calculate:

$$
\mu_0=\frac{1}{R}\sum_i D_i^0,
\qquad
s_0=\sqrt{\frac{1}{R-1}\sum_i(D_i^0-\mu_0)^2},
$$

$$
Z_A=\frac{D_{\mathrm{obs}}-\mu_0}{s_0},
$$

and

$$
P_A=\frac{1+\sum_i\mathbf{1}(D_i^0\ge D_{\mathrm{obs}})}{R+1}.
$$

Implementation details:

- calculate the sample standard deviation with `ddof=1`;
- count ties as exceedances with `>=`;
- use the add-one numerator and denominator exactly as shown;
- require at least two null values for a Z-score;
- reject nonfinite or negative distances; and
- fail if `null_sd` is zero rather than emitting an infinite Z-score.

The function should also return standardized null values
$Z_i^0=(D_i^0-\mu_0)/s_0$ for plotting and later category contrasts.

## 4. Changes to `calculate()`

Refactor the current single loop into these stages:

1. validate provenance and the existing bootstrap-target match schema;
2. load $A$, $B_0$, and $B_1,\ldots,B_R$;
3. scan the VCF once for the union of all requested coordinates;
4. apply the TE and SNP polarity paths separately and project each distinct
   site state once;
5. assert that every set has exactly $M$ eligible sites;
6. accumulate and normalize all spectra;
7. calculate
   $D_{\mathrm{obs}}=\Phi_{\mathrm{SFS}}(A,B_0)$;
8. calculate
   $D_i^0=\Phi_{\mathrm{SFS}}(B_i,B_0)$ for every null replicate;
9. call `calibrate_phi()`; and
10. publish all outputs atomically under the new schema.

Keep $B_0$ fixed for every comparison in one analysis. Do not calculate the
observed statistic against the average SNP SFS: that would have a different
finite-sample distribution from each $B_i$-to-$B_0$ null distance.

Vectorize the distance calculation after constructing the SFS matrix:

```python
snp_cdf = np.cumsum(snp_normalized, axis=1)
reference_cdf = snp_cdf[reference_index]
null_cdf = np.delete(snp_cdf, reference_index, axis=0)
null_phi = (
    np.abs(null_cdf[:, :-1] - reference_cdf[:-1])
    * np.diff(daf)
).sum(axis=1)
```

This avoids a Python loop over bins and is trivial in memory relative to the
existing matched-site arrays.

## 5. CLI and configuration

Keep the current required inputs and add:

- `-A/--a-type {TE,SNP}`: focal dataset type, default `TE`;
- `-B/--b-type {SNP}`: control dataset type, default `SNP`;
- `--reference-replicate ID`: optional explicit $B_0$ identifier, defaulting to
  a prespecified replicate such as ID 0;
- `--null-replicates N`: the exact null count $R$ (first $N$ QC-passing
  non-reference sets in replicate-ID order), default 1000 for production, with an explicit
  override for tests and pilots; and
- `--reference-sensitivity N`: optionally repeat calibration for $N$ additional
  prespecified reference sets.

The CLI should fail when:

- the match bundle does not use a supported age-bootstrap schema;
- the bundle was not generated with `--disjoint-replicates`, or its maximum
  control reuse exceeds 1;
- the declared reference is missing or fails QC;
- fewer than the requested null replicates pass matching QC;
- site counts differ after filtering;
- matching used allele-frequency information; or
- the null standard deviation is zero.

Reference selection and QC filtering must occur before reading or calculating
any SFS, preventing outcome-dependent selection.

Continue atomic publication and the no-overwrite rule.

## 7. No nested outer A-set bootstrap

Do not add an outer loop that resamples $A$, rebuilds the target, and generates
a new collection of neutral sets inside every resample. The existing matcher
already bootstraps focal A sites once per $B_r$ to propagate variation in the focal-age
target. The production calculation uses that existing collection directly:

$$
D_{\mathrm{obs}}=\Phi_{\mathrm{SFS}}(A,B_0),
\qquad
D_i^0=\Phi_{\mathrm{SFS}}(B_i,B_0).
$$

This is a single composite neutral null. It does not bootstrap the observed A
SFS and therefore should not be described as a confidence interval for
re-observing a different collection of focal sites. That limitation is reported, not
addressed by rerunning the entire pipeline in a nested bootstrap.

## 8. Formal comparisons between TE categories

Put between-category inference in a separate aggregation module so the
single-category calculation remains simple and reproducible.

For categories 1 and 2, calculate:

$$
\Delta_{\mathrm{obs}}=Z_{A_1}-Z_{A_2}
$$

and null contrasts:

$$
\Delta_i^0=Z_{1i}^0-Z_{2i}^0.
$$

If replicate seeds encode a shared bootstrap draw across categories, preserve
that pairing. Otherwise use a prespecified deterministic random pairing and
repeat it as a sensitivity analysis, or use all cross-pairs when feasible.
Calculate the two-sided add-one P-value from
$|\Delta_i^0|\ge|\Delta_{\mathrm{obs}}|$.

Report multiplicity correction for any family of category contrasts. A plot of
two category Z-scores is descriptive until this contrast is performed.

## 9. Test plan

### 9.1 Pure Wasserstein tests

- identical normalized spectra give zero;
- point masses at DAF 0.05 and 0.95 give 0.90;
- moving the same mass twice as far doubles Φ-SFS;
- swapping inputs leaves the scalar unchanged and reverses signed diagnostics;
- direct CDF integration agrees with `scipy.stats.wasserstein_distance` on
  randomized spectra, if SciPy remains an available test dependency;
- irregular DAF grids use `np.diff(daf)` correctly; and
- malformed, negative, nonfinite, or unnormalized inputs fail.

### 9.2 Polarity-path tests

- a TE at exactly 50% derived support and one above 50% are both retained;
- a retained TE uses insertion presence as the derived allele;
- an ALT-derived SNP draw contributes at frequency $p$;
- a REF-derived SNP draw contributes at frequency $1-p$;
- mixed SNP orientation agrees with
  $q\,h(k,n)+(1-q)\,h(n-k,n)$;
- SNPs with $q<0.5$, $q=0.5$, and $q>0.5$ are all retained when otherwise
  eligible; and
- unusable ARG draws are reported and do not count toward either orientation.

### 9.3 Calibration tests

- a hand-calculated null vector gives the expected mean, sample SD, Z,
  exceedance count, and add-one P-value;
- ties use `>=`;
- the smallest possible P-value is $1/(R+1)$, never zero;
- fewer than two null values and zero null variance fail;
- standardized null scores have mean zero and sample SD one; and
- calibration is invariant to permutation of null replicates.

### 9.4 Bundle and integration tests

- every set has exactly $M$ eligible sites;
- reference and null identities survive into every output;
- the reference is chosen before SFS calculation and was generated by the same
  bootstrap-matching path as every other set;
- each null row records its overlap with $B_0$, which must be 0, and the bundle's
  maximum control reuse is verified to be 1;
- a bundle generated without `--disjoint-replicates`, or with any shared
  control, fails clearly;
- unsupported match schemas and old Φ-SFS output schemas fail clearly;
- fixed inputs and seeds reproduce byte-equivalent numerical arrays;
- atomic output cleanup still works after an injected failure; and
- output arrays independently reproduce summary values.

### 9.5 Statistical validation

Run repeated independent simulations under a neutral exchangeable model and
verify:

- Monte Carlo P-values are approximately uniform;
- type-I error is close to the nominal level;
- null Z-scores are centered near zero with unit variance;
- the null mean rises as $M$ decreases, while calibrated type-I error remains
  stable; and
- sequential pool depletion under disjoint sampling leaves type-I error
  calibrated at the production replicate count, with no trend in matching error
  or null distance across replicate index.

Under prespecified rare-variant and high-frequency shifts, verify that power and
Z increase with effect size and $M$, while the signed diagnostics recover the
correct direction.

## 10. Implementation sequence

1. Add pure Wasserstein and calibration functions with unit tests.
2. Build the shared VCF eligibility mask, add the separate TE/SNP polarity
   paths, support `TE`-versus-`SNP` and `SNP`-versus-`SNP`, exclude A sites
   from the B pool, and enforce equal retained site counts.
3. Configure the existing bootstrap matcher to publish $R+1$ sets; do not
   change its age target, objective, or optimizer, and run it with
   `--disjoint-replicates` after confirming that $(R+1)\,M$ fits in the pool.
4. Refactor `calculate()` to designate one disjoint replicate as the reference
   and use the other $R$ sets for vectorized null distances.
5. Publish the new arrays, summary tables, metadata, and schema guards.
6. Replace old end-to-end tests and add statistical calibration tests.
7. Add reference-rotation sensitivity.
8. Add the separate between-category contrast module.

## 11. Acceptance criteria

The revised implementation is ready when:

1. old and new outputs cannot be confused by schema or filename;
2. the direct implementation passes analytic and trusted-library comparisons;
3. every observed and null comparison uses exactly $M$ eligible sites;
4. the TE at-least-half-derived filter and SNP posterior-flipping rule are tested and
   recorded independently;
5. $B_0$ is selected blindly from the disjoint matched replicates and is
   demonstrably generated by the same procedure as every $B_i$;
6. Z and P are reproducible from published raw distances;
7. add-one P-values have validated neutral calibration at relevant site counts;
8. matching error, overlap with $B_0$ (zero), maximum SNP reuse (one), pool
   depletion, and reference sensitivity are reported;
9. the current CLI, README, Slurm launcher, and changelog agree on the new
   semantics; and
10. representative end-to-end runs finish within the current memory and runtime
   envelope before production deployment.
